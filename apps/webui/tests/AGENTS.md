# Purpose
Test files for WebUI components and functionality.

# Entrypoints & Commands
- Run tests: `npm test` (from parent directory)
- Playwright tests: `npx playwright test`

# Interfaces
- Test files with `.test.ts` or `.spec.ts` extensions
- Playwright test files

# Constraints
- Use Playwright for E2E tests
- Test all major user flows
- Mock external API calls

# Gotchas
- Tests run in headless mode by default
- Install browser dependencies first

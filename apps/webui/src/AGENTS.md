# Purpose
React source code for WebUI.

# Entrypoints & Commands
- Dev: `npm run dev` (from parent directory)
- Build: `npm run build` (from parent directory)

# Interfaces
- Components in `components/`
- Utilities in `lib/`
- Tests in `tests/`

# Constraints
- TypeScript strict mode
- Tailwind CSS for styling
- Port 5173 locked

# PR-0043: Eliminate Mocks, Enforce Real Services Only

## Summary
Surgical removal of all mock infrastructure and enforcement of real service endpoints only. This PR eliminates the possibility of falling back to mocks and ensures all orchestration calls reach real services.

## Changes

### 1. Delete Mock Infrastructure
- [ ] Remove `make mock-serve` target from Makefile
- [ ] Delete any mock service files in `scripts/` or `services/`
- [ ] Remove mock-related environment variables from `.env.example`

### 2. Update Environment Configuration
- [ ] Set `MOCK_LMS=0` and `DISABLE_MOCKS=1` in `.env.example`
- [ ] Add required service URLs to `.env.example`:
  ```
  NARRATIVE_BASE=http://127.0.0.1:8001
  WORLDCORE_BASE=http://127.0.0.1:8000
  SCREENPLAY_BASE=http://127.0.0.1:8002
  MEDIA_BASE=http://127.0.0.1:8003
  INTERACT_BASE=http://127.0.0.1:8004
  ```

### 3. Tighten Guards
- [ ] Update `ci/no_mocks_env_guard.sh` to fail on any mock-related variables
- [ ] Add validation in orchestration startup to ensure real service URLs are present
- [ ] Update documentation to reflect no-mock policy

### 4. Fix Orchestration Service
- [ ] Ensure orchestration service loads environment variables correctly
- [ ] Add validation that service URLs are properly formatted
- [ ] Update startup scripts to export required environment variables
